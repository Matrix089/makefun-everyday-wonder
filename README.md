A tiny Python program that writes one original sentence about a small moment of wonder in everyday life to /output/entry.txt for make.fun's Everyday Wonder, Two Days to Find the Line bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
